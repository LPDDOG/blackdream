# Black Dream · 地下乐队成长记

打开 `index.html` 即可在浏览器本地游玩，无安装和构建步骤。也可以通过静态网站托管仓库根目录。

五章主线跨越 2016—2024 年；尾声为 2025 年，重聚延伸至 2030 年。每章三个时期，每期两次行动、一则故事，章末编排歌单、完成三段现场互动。目标单局约 20—30 分钟，实际时长取决于阅读与决策速度。

先回应故事再安排行动，有助于及时兑现承诺。排练提高作品完成度；写歌和录音增加发行作品；共同创作改善署名与分配；休息照顾体力和关系。每期推进时结算 ¥100 房租。第五章提出未来方向，最终结局还会检查此前的积累。

进度自动保存在当前浏览器。开场可选择继续；重新开始新故事会覆盖原存档。浏览器清理数据或禁用本地存储可能使存档丢失。声音默认关闭，需主动开启，提供音量控制。音频是原创合成器动机，不是完整歌曲或真实乐队作品。

六类结局：全国巡演、独立厂牌、小众长青、体面告别、决裂解散、暂停重聚。结局可导出文字手记。

素材与发布审查边界见 ASSETS.md。源码可直接编辑，无第三方运行依赖。


界面采用炭黑、暖白与摇滚红。Black Dream 是个人命名致意，不使用真实专辑封面、歌曲或标志，也无官方关联。
